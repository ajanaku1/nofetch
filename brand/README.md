# NoFetch identity

The Local Return mark turns an outward route back toward local evidence. Its open outer edge is the fetch gate. The path can continue, but never silently.

## Files

- `finals/logo.svg`: mint mark for dark backgrounds
- `finals/logo-light.svg`: ink mark for light backgrounds
- `finals/logo-monochrome.svg`: one-color mark
- `finals/logo-combination.svg`: mark with outlined wordmark
- `finals/favicon.svg` and `finals/favicon.ico`: browser icons
- `finals/logo.png`: 512px transparent PNG
- `finals/og-image.png`: 1200 by 630 social preview

Keep clear space equal to one stroke width around the mark. Do not rotate the mark, close the outer gate, add effects, or introduce another accent color.

All SVGs are authored vectors. No image model or upscaling was used.
